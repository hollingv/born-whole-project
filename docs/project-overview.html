Mission & Overview Bodily Integrity Commons

What is Bodily Integrity Commons?

Bodily Integrity Commons (BIC) is an open-source advocacy hub dedicated to raising awareness about the harms of genital cutting, connecting people with trusted organizations, and empowering parents and the general public to make informed decisions.

"Every child deserves the right to bodily autonomy. Access to accurate, compassionate information can change outcomes for children around the world."

BIC serves as a central resource — a dispatching hub — that aggregates information from dozens of advocacy organizations and makes it accessible through a modern, AI-powered web interface. Rather than duplicating the work of existing organizations, BIC amplifies it.

Core Purpose

  • Education — helping parents, healthcare providers and the general public understand the medical, ethical and legal dimensions of genital cutting
  • Connection — directing people to the organizations leading the fight to protect children's bodily integrity
  • Action — supporting the legal and advocacy efforts working to end this practice
  • Infrastructure — providing a shared technical platform that grows stronger as more organizations participate

The Dispatching Hub Model

BIC defines a lightweight protocol — a standard set of URL patterns that organizations publish content under. Organizations that adopt these patterns are automatically integrated into BIC's features, including the knowledge base, news aggregation, and AI question answering.

For the Public

A single place to find vetted organizations, watch educational videos, read FAQs, and ask natural language questions answered by AI.

For Organizations

Automatic inclusion in a growing hub. Adopt standard URL patterns and your content is surfaced to a wider audience automatically.

Open Source & Collaboration Bodily Integrity Commons

Built in the Open, Built Together

BIC is developed entirely in the open on GitHub. Every line of code, every design decision, and every piece of content is publicly visible and open to contribution. This is not an accident — it is a deliberate choice that makes the project stronger.

Why Open Source?

  • Trust — anyone can audit the code, verify that no data is collected, and confirm that the AI is grounded in vetted sources
  • Resilience — the project cannot be shut down, taken over, or defunded by any single party
  • Velocity — developers, advocates and organizations can contribute improvements without waiting for permission
  • Credibility — open code signals transparency and accountability to the public

How Organizations Join

Any advocacy organization can add themselves to BIC with a simple GitHub pull request — no technical expertise beyond a GitHub account is required:

  • Open src/cmd/gacli/organizations.go in the GitHub web editor
  • Add an entry with the organization's name, description, website, and content URLs
  • Submit a pull request — a maintainer reviews and merges
The pull request model means every addition is reviewed, every organization is vetted, and the history of every change is permanently recorded.

How Developers Contribute

BIC welcomes contributions across all areas of the project:

Code

Go backend, HTML templates, CSS, JavaScript, CI/CD pipeline, AI integration.

Content

FAQ entries, organization listings, knowledge base URL curation, resource videos.

Design

UI improvements, accessibility, mobile experience, visual identity.

Research

Identifying high-quality sources, verifying organization information, curating YouTube content.

Technical Architecture

BIC is built on a modern, low-cost, high-reliability stack. The guiding principle is simplicity — a static site with serverless functions, deployed to a global CDN.

The Knowledge Base Pipeline

The AI question-answering feature is powered by a Retrieval-Augmented Generation (RAG) pipeline:

  • Harvest — gacli harvest fetches content from organization websites and YouTube, extracts meaningful prose, and stores it as text files committed to git
  • Search — when a user submits a question, keywords are extracted and the most relevant paragraphs are identified
  • Answer — the relevant content is sent to Cloudflare Workers AI along with the question; the LLM synthesizes a natural language answer grounded in the KB

Deployment Strategy

Pushes to main deploy to the production site. Pushes to devel deploy to a separate preview URL, enabling safe testing before production release. Integration tests run automatically after every deployment.

Vision & Getting Involved Bodily Integrity Commons

Intactivist Infrastructure

BIC's ambition extends beyond a single website. The goal is to become the shared technical infrastructure for the intactivist movement — a platform that every organization, advocate, researcher and parent can rely on.

The URL Convention Protocol

BIC defines a standard set of URL paths that organizations are encouraged to adopt. Organizations that publish content at these paths are automatically integrated into BIC's aggregation features:

PathContent
/aboutOrganization background and mission
/researchAcademic and medical research
/legal-casesActive and completed legal cases
/newsNews and press coverage
/eventsUpcoming events and actions

This mirrors how RSS worked — sites that publish a feed get aggregated automatically. Organizations that adopt BIC's URL protocol gain visibility across all of BIC's current and future features.

The Roadmap

  • Semantic search using embeddings (Cloudflare Vectorize) for more accurate AI answers
  • News and events aggregation pages that pull from all registered organizations
  • A legal case tracker drawing from organizations' /legal-cases pages
  • Multilingual support to reach parents globally
  • Conformance indicators showing which organizations support which URL patterns

Getting Involved

Organizations

Submit a pull request to add your organization to organizations.go. Visit the Contribute page on the site for step-by-step instructions.

Developers

Fork the repository on GitHub, explore the codebase, and open a pull request. All skill levels welcome.

Advocates

Suggest organizations to feature, identify high-quality knowledge base URLs, or contribute to the FAQ.

Researchers

Help identify the most informative pages on each organization's site to include in the knowledge base.

BIC is not owned by any single organization. It is shared infrastructure, built by the movement, for the movement. Every contribution — however small — makes it stronger.
